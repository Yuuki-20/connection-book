# ビジコン・支援情報の自動登録（森岡さん向けの反映手順）

イベント自動収集ボット（メグリネのNECで動くGemini）が、毎週日曜20時に選んだ情報を
つながり帳の「ビジコン」タブ（締切のあるもの）と「支援」タブ（締切のない、いつでも使える支援）に自動で登録します。

## 反映の順番（この順番を守ってください）

1. **SQLを先に実行**：Supabaseの SQL エディターで `supabase/migrations/20261121000000_business_contest_kind.sql` を実行します。
   - これを先にしないと、マージ後に「ビジコン」タブが開けなくなります。
2. **Vercelに環境変数を追加**（Production）：
   - `BIZCON_INGEST_TOKEN` … 川西さんから受け取った長い文字列（32文字以上）。ボットの合言葉です。
   - `BIZCON_CLUB_ID` … 空でOK（クラブが1つなら自動で決まります）。
3. この PR をマージして、Vercel の反映を待ちます。

## 動き

- 受け取り口は `POST /api/bizcon-ingest`。合言葉（`Authorization: Bearer <BIZCON_INGEST_TOKEN>`）がないと 401 で断ります。合言葉が未設定なら常に断ります。
- 同じ種類で同じURLのものは二度登録しません。
- 登録者はクラブのオーナー、カードには「AI収集」の印が付きます。
- 幹部はアプリ上でいつでも編集・削除できます。支援は幹部が手で追加もできます。
