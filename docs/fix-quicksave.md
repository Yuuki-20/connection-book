# 保存のみの調査

現在のソースでは「保存のみ」の選択と `mode=quick` はクイックとして処理され、重複確認で上書き・併記・別人を選んだ後も保存して完了する。重要ではGmail下書きを作り、礼儀では送信画面に進む。報告された症状はこのソースだけでは再現できておらず、実際の発生原因は未確定。

撮影画面を開いたままURLのモードだけが変わると、画面の選択状態が初回の値のまま残り、重要なら下書き、礼儀なら送信画面に進みうるため、URL変更時に選択状態を作り直す。登録APIはクイックを未判断に限定し、下書きは作成しない。既存の重要人物への併合では分類を維持するため、下書きAPIにもクイック指定を拒否する検査を追加した。ただし別のAPI呼び出しでクイック指定を省略・偽装することまでは識別できない。
